# QuickRouteOut README

### Start by downloading the Protomaps CLI: https://github.com/protomaps/go-pmtiles/releases
### Next, download the Boston area pmtiles file from the server with this command: ./pmtiles extract https://build.protomaps.com/20261107.pmtiles Boston.pmtiles --bbox=-71.858446,41.964658,-70.760572,42.775768
### Put the .pmtiles map file into the /static folder under the home directory
### Finally in the home directory, run the app.py program with python or python3 app.py, and click the local ip: 127.0.0.1:port
